## 9. SQLを書くときの注意点・まとめ

### 9.1 SQLを読みやすく記述する

SQLが長くなる場合は、適切に改行して記述します。

```sql
SELECT
    id,
    name,
    age
FROM users
WHERE age >= 20
ORDER BY age DESC;
```

SQLを読みやすく記述することで、処理内容を確認しやすくなります。

---

### 9.2 データを変更・削除するSQLに注意する

`UPDATE` や `DELETE` を実行する場合は、`WHERE` の条件を確認します。

```sql
UPDATE users
SET age = 30
WHERE id = 1;
```

また、必要に応じて、実行前に `SELECT` を使用して対象となるデータを確認します。

```sql
SELECT *
FROM users
WHERE id = 1;
```

対象データを確認してから更新・削除を行うことで、意図しないデータを変更・削除することを防ぎやすくなります。

---

### 9.3 SQLの基本操作まとめ

本教材では、SQLの基本的な操作について説明しました。

| SQL・機能     | 用途               |
| ---------- | ---------------- |
| `SELECT`   | データを取得する         |
| `WHERE`    | 条件を指定する          |
| `ORDER BY` | データを並べ替える        |
| `INSERT`   | データを登録する         |
| `UPDATE`   | データを更新する         |
| `DELETE`   | データを削除する         |
| 集計関数       | データを集計する         |
| `GROUP BY` | データをグループ化する      |
| `JOIN`     | 複数のテーブルを結合する     |
| サブクエリ      | SQLの中で別のSQLを使用する |

SQLを扱ううえでは、文法だけでなく、テーブル・カラム・レコード・主キー・外部キーなどのデータベースに関する知識も重要です。

まずは `SELECT`、`WHERE`、`ORDER BY` などの基本的なSQLを実際に実行し、データの取得方法を理解することから始めましょう。
