## 8. 主キー・外部キー・トランザクション

### 8.1 主キーとは

**主キー（Primary Key）**とは、テーブルのレコードを一意に識別するためのカラムです。

例えば、`users` テーブルの `id` を主キーとした場合、ユーザーごとに異なるIDを持つことになります。

| id | name |
| -- | ---- |
| 1  | 山田太郎 |
| 2  | 佐藤花子 |
| 3  | 鈴木一郎 |

---

### 8.2 外部キーとは

**外部キー（Foreign Key）**とは、別のテーブルの主キーなどを参照するためのカラムです。

例えば、以下のテーブルがあるとします。

### users

| id | name |
| -- | ---- |
| 1  | 山田太郎 |
| 2  | 佐藤花子 |

### orders

| id | user_id | product_name |
| -- | ------- | ------------ |
| 1  | 1       | ノートPC        |
| 2  | 2       | マウス          |

この場合、`orders.user_id` は `users.id` を参照しています。

このように、主キーと外部キーを利用することで、テーブル同士の関係を表現できます。

---

### 8.3 トランザクションとは

**トランザクション**とは、複数のSQL処理をひとまとまりとして扱う仕組みです。

例えば、銀行口座からお金を移動する処理では、

1. Aさんの口座からお金を減らす
2. Bさんの口座にお金を増やす

という複数の処理が必要になります。

この途中でエラーが発生すると、片方だけ処理されてしまい、データの整合性が崩れる可能性があります。

そのため、複数の処理を1つのトランザクションとして扱います。

---

### 8.4 COMMIT

**`COMMIT`** は、トランザクション内で行った変更を確定します。

```sql
COMMIT;
```

---

### 8.5 ROLLBACK

**`ROLLBACK`** は、トランザクション内で行った変更を取り消します。

```sql
ROLLBACK;
```

---

### 8.6 まとめ

* 主キーはレコードを一意に識別する
* 外部キーは別のテーブルのデータを参照するために使用する
* トランザクションは複数の処理をひとまとまりとして扱う
* `COMMIT` で変更を確定する
* `ROLLBACK` で変更を取り消す

---
