# 6. ウィンドウ関数

## 6.1 ウィンドウ関数とは

**ウィンドウ関数**とは、現在の行を残したまま、他の行のデータを利用して計算を行うための関数です。

通常の集計関数では、`GROUP BY` を使用すると複数の行が1つのグループにまとめられます。

例えば、部署ごとの平均年齢を取得する場合は以下のように記述します。

```sql
SELECT
    department,
    AVG(age) AS average_age
FROM employees
GROUP BY department;
```

この場合、部署ごとに1行の結果になります。

一方、ウィンドウ関数を使用すると、**元の行を残したまま、部署ごとの平均年齢などの情報を各行に追加できます。**

```sql
SELECT
    name,
    department,
    age,
    AVG(age) OVER (
        PARTITION BY department
    ) AS average_age
FROM employees;
```

結果は以下のようになります。

| name | department | age | average_age |
| ---- | ---------- | --: | ----------: |
| 山田太郎 | 営業部        |  25 |          30 |
| 佐藤花子 | 営業部        |  35 |          30 |
| 鈴木一郎 | 開発部        |  28 |          32 |
| 田中次郎 | 開発部        |  36 |          32 |

`GROUP BY` では部署ごとに行がまとめられましたが、ウィンドウ関数では社員ごとの行を残したまま、部署ごとの平均年齢を表示しています。

---

## 6.2 OVER句

ウィンドウ関数では、**`OVER` 句**を使用します。

基本的な構文は以下のとおりです。

```sql
関数() OVER (
    PARTITION BY グループ化するカラム
    ORDER BY 並べ替えるカラム
)
```

`OVER` 句では、どのデータを対象として計算するかを指定します。

主に以下の2つを使用します。

| 指定             | 説明            |
| -------------- | ------------- |
| `PARTITION BY` | データをグループに分ける  |
| `ORDER BY`     | グループ内の順番を指定する |

---

## 6.3 PARTITION BY

`PARTITION BY` は、ウィンドウ関数の対象となるデータをグループに分けるために使用します。

例えば、部署ごとに社員番号を振る場合は以下のように記述できます。

```sql
SELECT
    name,
    department,
    ROW_NUMBER() OVER (
        PARTITION BY department
        ORDER BY age DESC
    ) AS row_num
FROM employees;
```

結果は以下のようになります。

| name | department | age | row_num |
| ---- | ---------- | --: | ------: |
| 佐藤花子 | 営業部        |  35 |       1 |
| 山田太郎 | 営業部        |  25 |       2 |
| 田中次郎 | 開発部        |  36 |       1 |
| 鈴木一郎 | 開発部        |  28 |       2 |

`PARTITION BY department` によって、営業部と開発部がそれぞれ別のグループとして扱われています。

---

## 6.4 ROW_NUMBER()

**`ROW_NUMBER()`** は、対象となる行に連番を付ける関数です。

```sql
SELECT
    name,
    age,
    ROW_NUMBER() OVER (
        ORDER BY age DESC
    ) AS row_num
FROM employees;
```

年齢の高い順に1から連番が付けられます。

例えば、

| name | age | row_num |
| ---- | --: | ------: |
| 田中次郎 |  45 |       1 |
| 佐藤花子 |  35 |       2 |
| 山田太郎 |  30 |       3 |
| 鈴木一郎 |  25 |       4 |

となります。

---

## 6.5 ROW_NUMBER()とPARTITION BY

`ROW_NUMBER()` と `PARTITION BY` を組み合わせることで、グループごとに連番を付けることができます。

```sql
SELECT
    name,
    department,
    age,
    ROW_NUMBER() OVER (
        PARTITION BY department
        ORDER BY age DESC
    ) AS row_num
FROM employees;
```

この場合、部署が変わると番号が1に戻ります。

```text
営業部
  1
  2
  3

開発部
  1
  2
  3
```

---

## 6.6 RANK()

**`RANK()`** は、順位を付けるための関数です。

```sql
SELECT
    name,
    score,
    RANK() OVER (
        ORDER BY score DESC
    ) AS ranking
FROM students;
```

同じ点数のデータがある場合、同じ順位になります。

例えば、

| name | score | ranking |
| ---- | ----: | ------: |
| 山田   |   100 |       1 |
| 佐藤   |    90 |       2 |
| 鈴木   |    90 |       2 |
| 田中   |    80 |       4 |

となります。

90点が2人いるため、次の80点は3位ではなく4位になります。

---

## 6.7 DENSE_RANK()

**`DENSE_RANK()`** も順位を付けるための関数です。

`RANK()` と似ていますが、同じ順位が存在しても次の順位を飛ばしません。

```sql
SELECT
    name,
    score,
    DENSE_RANK() OVER (
        ORDER BY score DESC
    ) AS ranking
FROM students;
```

結果は以下のようになります。

| name | score | ranking |
| ---- | ----: | ------: |
| 山田   |   100 |       1 |
| 佐藤   |    90 |       2 |
| 鈴木   |    90 |       2 |
| 田中   |    80 |       3 |

`RANK()` と `DENSE_RANK()` の違いは、同順位があった場合の次の順位です。

| 関数             | 100 | 90 | 90 | 80 |
| -------------- | --: | -: | -: | -: |
| `RANK()`       |   1 |  2 |  2 |  4 |
| `DENSE_RANK()` |   1 |  2 |  2 |  3 |

---

## 6.8 ウィンドウ関数と集計関数

ウィンドウ関数では、`SUM()`、`AVG()`、`COUNT()` などの集計関数も使用できます。

例えば、部署ごとの平均給与を各社員の行に表示する場合は以下のように記述します。

```sql
SELECT
    name,
    department,
    salary,
    AVG(salary) OVER (
        PARTITION BY department
    ) AS department_average_salary
FROM employees;
```

このSQLでは、社員ごとの給与を残したまま、所属部署の平均給与を取得しています。

---

## 6.9 累計を求める

ウィンドウ関数を使用すると、累計を求めることもできます。

例えば、注文日ごとの売上金額と累計売上を取得する場合は以下のように記述できます。

```sql
SELECT
    order_date,
    amount,
    SUM(amount) OVER (
        ORDER BY order_date
    ) AS cumulative_amount
FROM orders;
```

例えば、以下のような結果になります。

| order_date | amount | cumulative_amount |
| ---------- | -----: | ----------------: |
| 2026-01-01 |   1000 |              1000 |
| 2026-01-02 |   2000 |              3000 |
| 2026-01-03 |   1500 |              4500 |
| 2026-01-04 |   3000 |              7500 |

`ORDER BY order_date` によって日付順に処理され、それまでの売上金額が累積されます。

---

## 6.10 前後の行を参照する

ウィンドウ関数には、現在の行の前後にあるデータを取得する関数もあります。

代表的なものとして、以下があります。

| 関数       | 説明         |
| -------- | ---------- |
| `LAG()`  | 前の行の値を取得する |
| `LEAD()` | 次の行の値を取得する |

例えば、前日の売上金額を取得する場合は以下のように記述できます。

```sql
SELECT
    order_date,
    amount,
    LAG(amount) OVER (
        ORDER BY order_date
    ) AS previous_amount
FROM orders;
```

結果は以下のようになります。

| order_date | amount | previous_amount |
| ---------- | -----: | --------------: |
| 2026-01-01 |   1000 |            NULL |
| 2026-01-02 |   2000 |            1000 |
| 2026-01-03 |   1500 |            2000 |
| 2026-01-04 |   3000 |            1500 |

最初の行には前の行が存在しないため、`NULL` になります。

---

## 6.11 ウィンドウ関数を使用した実践例

例えば、「部署ごとに給与の高い社員から順位を付ける」場合は以下のように記述できます。

```sql
SELECT
    name,
    department,
    salary,
    RANK() OVER (
        PARTITION BY department
        ORDER BY salary DESC
    ) AS salary_rank
FROM employees;
```

このSQLでは、

1. `department` ごとにデータを分ける
2. 各部署内で `salary` の高い順に並べる
3. `RANK()` で順位を付ける

という処理を行っています。

---

## 6.12 ROW_NUMBER()・RANK()・DENSE_RANK()の使い分け

これらの関数は似ていますが、目的が異なります。

| 関数             | 特徴                    | 主な用途         |
| -------------- | --------------------- | ------------ |
| `ROW_NUMBER()` | 必ず異なる連番を付ける           | グループ内で1件だけ選ぶ |
| `RANK()`       | 同じ値には同じ順位を付け、順位を飛ばす   | ランキング        |
| `DENSE_RANK()` | 同じ値には同じ順位を付け、順位を飛ばさない | ランキング        |

例えば、各部署から給与が最も高い社員を1人取得したい場合、`ROW_NUMBER()` が利用できます。

```sql
SELECT *
FROM (
    SELECT
        name,
        department,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department
            ORDER BY salary DESC
        ) AS row_num
    FROM employees
) AS ranked_employees
WHERE row_num = 1;
```

このSQLでは、まず部署ごとに給与順の番号を付け、その後、`row_num = 1` のデータだけを取得しています。

---

## 6.13 ウィンドウ関数を使用するときの注意点

ウィンドウ関数では、`ORDER BY` の指定が結果に大きく影響する場合があります。

例えば、

```sql
ROW_NUMBER() OVER (
    ORDER BY salary DESC
)
```

と、

```sql
ROW_NUMBER() OVER (
    ORDER BY salary ASC
)
```

では、付けられる番号が逆になります。

また、同じ値を持つデータがある場合、`ROW_NUMBER()` ではどの行が先になるかを明確にするため、複数のカラムを `ORDER BY` に指定することがあります。

```sql
ROW_NUMBER() OVER (
    ORDER BY salary DESC, id ASC
)
```

このように、順位や連番の基準を明確にすることが重要です。

---

## 6.14 まとめ

* ウィンドウ関数は、現在の行を残したまま他の行を利用して計算できる
* `OVER` 句を使用して計算対象を指定する
* `PARTITION BY` でデータをグループに分けられる
* `ROW_NUMBER()` で連番を付けられる
* `RANK()` や `DENSE_RANK()` で順位を付けられる
* `SUM()` や `AVG()` と組み合わせて集計結果を各行に表示できる
* `LAG()` や `LEAD()` で前後の行の値を取得できる
* `ORDER BY` の指定によって結果が変わるため、並び順を意識する必要がある

ウィンドウ関数を使用することで、**「グループごとの集計結果を表示しながら、元のデータも残したい」**といった処理ができるようになります。

特に、ランキング・順位付け・累計・前後のデータとの比較など、通常の `GROUP BY` では扱いにくい処理で活用されます。
