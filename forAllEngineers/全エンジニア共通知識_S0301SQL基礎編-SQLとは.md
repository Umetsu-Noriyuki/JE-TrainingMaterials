# SQL入門

## 1. SQLとは

### 1.1 SQLの概要

**SQL（Structured Query Language）**とは、データベースに保存されているデータを操作するための言語です。

SQLを使用することで、データベースに対して以下のような操作を行うことができます。

* データを取得する
* データを登録する
* データを更新する
* データを削除する
* 条件を指定してデータを検索する
* 複数のテーブルを組み合わせてデータを取得する

例えば、`users` テーブルからデータを取得する場合、以下のように記述します。

```sql
SELECT *
FROM users;
```

---

### 1.2 データベースとは

**データベース（Database）**とは、データを整理して保存し、必要なときに検索・利用できるようにした仕組みです。

例えば、Webサービスでユーザー情報を管理する場合、以下のようなデータをデータベースに保存します。

| ユーザーID | 名前   | 年齢 | メールアドレス                                         |
| ------ | ---- | -- | ----------------------------------------------- |
| 1      | 山田太郎 | 25 | [taro@example.com](mailto:taro@example.com)     |
| 2      | 佐藤花子 | 30 | [hanako@example.com](mailto:hanako@example.com) |
| 3      | 鈴木一郎 | 22 | [ichiro@example.com](mailto:ichiro@example.com) |

---

### 1.3 テーブル・カラム・レコード

データベースでは、データを**テーブル（Table）**という単位で管理します。

テーブルは、Excelなどの表に近いイメージです。

| id | name | age | email                                           |
| -- | ---- | --- | ----------------------------------------------- |
| 1  | 山田太郎 | 25  | [taro@example.com](mailto:taro@example.com)     |
| 2  | 佐藤花子 | 30  | [hanako@example.com](mailto:hanako@example.com) |
| 3  | 鈴木一郎 | 22  | [ichiro@example.com](mailto:ichiro@example.com) |

それぞれの用語には以下の意味があります。

| 用語   | 説明         | Excelに例えると |
| ---- | ---------- | ---------- |
| テーブル | データを管理する単位 | 表          |
| カラム  | データの項目     | 列          |
| レコード | 1件分のデータ    | 行          |

例えば、上記の `users` テーブルでは、

* `id`
* `name`
* `age`
* `email`

がカラムです。

また、

```text
1 | 山田太郎 | 25 | taro@example.com
```

が1件のレコードです。
