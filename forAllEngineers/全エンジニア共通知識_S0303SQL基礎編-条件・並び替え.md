## 3. 条件・並び替え

### 3.1 WHERE句

**`WHERE`** は、取得するデータに条件を指定するときに使用します。

例えば、20歳以上のユーザーを取得する場合は以下のように記述します。

```sql
SELECT *
FROM users
WHERE age >= 20;
```

---

### 3.2 比較演算子

条件を指定するときは、比較演算子を使用します。

| 演算子  | 意味    |
| ---- | ----- |
| `=`  | 等しい   |
| `<>` | 等しくない |
| `>`  | より大きい |
| `<`  | より小さい |
| `>=` | 以上    |
| `<=` | 以下    |

文字列を条件に指定する場合は、シングルクォーテーション（`'`）で囲みます。

```sql
SELECT *
FROM users
WHERE name = '山田太郎';
```

---

### 3.3 複数の条件を指定する

複数の条件を指定する場合は、`AND` や `OR` を使用します。

#### AND

`AND` は、すべての条件を満たすデータを取得します。

```sql
SELECT *
FROM users
WHERE age >= 20
  AND age <= 30;
```

#### OR

`OR` は、指定した条件のいずれかを満たすデータを取得します。

```sql
SELECT *
FROM users
WHERE age < 20
   OR age > 30;
```

---

### 3.4 ORDER BY句

**`ORDER BY`** は、取得したデータを指定した順番に並べ替えるときに使用します。

```sql
SELECT *
FROM users
ORDER BY age;
```

`ORDER BY` では、昇順・降順を指定できます。

| 指定     | 意味 |
| ------ | -- |
| `ASC`  | 昇順 |
| `DESC` | 降順 |

```sql
SELECT *
FROM users
ORDER BY age DESC;
```

---

### 3.5 WHEREとORDER BYの組み合わせ

`WHERE` と `ORDER BY` を組み合わせることもできます。

```sql
SELECT *
FROM users
WHERE age >= 20
ORDER BY age DESC;
```

このSQLでは、20歳以上のユーザーを取得し、年齢の高い順に並べています。

---

### 3.6 まとめ

* `WHERE` で取得するデータの条件を指定する
* 比較演算子を使用して条件を指定できる
* `AND` で複数の条件をすべて満たすデータを指定できる
* `OR` で複数の条件のいずれかを満たすデータを指定できる
* `ORDER BY` でデータの並び順を指定する
* `ASC` は昇順、`DESC` は降順
