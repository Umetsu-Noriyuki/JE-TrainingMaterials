# HTTP / REST API応用編・総合演習

## 問題編

### 第1問：HTTPメソッド

ユーザー情報を取得するREST APIを呼び出したい。サーバー上のデータを変更せずに取得する場合、適切なHTTPメソッドはどれ？

- ① GET
- ② POST
- ③ PUT
- ④ DELETE

### 第2問：HTTPステータスコード

ログイン済みのユーザーが、アクセス権限を持っていない管理者専用APIにアクセスした。適切なHTTPステータスコードはどれ？

- ① 400 Bad Request
- ② 401 Unauthorized
- ③ 403 Forbidden
- ④ 404 Not Found

### 第3問：REST APIの設計

REST APIのエンドポイント設計として、適切な考え方をすべて選んでね。

- ① リソースを名詞で表現する
- ② HTTPメソッドで操作内容を表す
- ③ すべての操作をPOSTに統一する
- ④ URLに処理の手順を細かく記述する

### 第4問：エラーハンドリング

次の文章が正しいか、誤っているか答えてね。

APIが入力値の不正によって処理できなかった場合、クライアントが修正できる問題であれば、400番台のステータスコードが使用されることがある。

- ① 正しい
- ② 誤り

### 第5問：APIのセキュリティ

APIの通信をHTTPSにする主な目的として、最も適切なものはどれ？

- ① APIの処理速度を必ず向上させる
- ② 通信内容の盗聴や改ざんを防ぐ
- ③ APIのエラーを自動的に修正する
- ④ ログイン処理を不要にする

### 第6問：OpenAPI・Swagger

OpenAPIでAPI仕様を定義し、その仕様をブラウザ上で確認したり、リクエストを試したりするために利用できる代表的なツールはどれ？

- ① Swagger UI
- ② Git
- ③ SQLite
- ④ Flutter

### 第7問：FlutterからAPIを利用する

FlutterアプリからAPIを呼び出し、JSON形式のレスポンスを受け取った。

JSON文字列をDartで扱えるデータに変換するために使用する関数はどれ？

- ① `jsonEncode()`
- ② `jsonDecode()`
- ③ `toString()`
- ④ `Future()`

---

## 解答・解説編

### 第1問：① GET

GETは、サーバー上のリソースを取得するためのHTTPメソッド。

### 第2問：③ 403 Forbidden

403は、認証されていてもアクセス権限がない場合に使用する。

401は認証が必要な場合や、認証情報が無効な場合などに使用する。

### 第3問：①・②

REST APIでは、URLでリソースを表現し、HTTPメソッドで操作内容を表す。

### 第4問：① 正しい

入力値の不正など、クライアント側のリクエストに問題がある場合は、400番台のステータスコードが使用されることがある。

### 第5問：② 通信内容の盗聴や改ざんを防ぐ

HTTPSはTLSによって通信を暗号化し、安全性を高める仕組み。

### 第6問：① Swagger UI

Swagger UIはOpenAPI仕様を視覚的に表示し、ブラウザからAPIを試すこともできるツール。

### 第7問：② jsonDecode()

`jsonDecode()` はJSON文字列をDartで扱えるデータに変換する。

反対に、`jsonEncode()` はDartのデータをJSON文字列に変換する。
