# 演習問題

## 問題1：条件検索とNULL

30歳以上の社員を対象として、以下の項目を取得してください。

* 社員名
* 年齢
* 給与
* 賞与

ただし、賞与が `NULL` の場合は `0` として表示してください。

### 使用する主な構文

* `SELECT`
* `WHERE`
* `COALESCE`

---

## 問題2：JOINと集計

部署ごとの社員数と平均給与を取得してください。

取得する項目は以下とします。

* 部署名
* 社員数
* 平均給与

### 使用する主な構文

* `INNER JOIN`
* `COUNT`
* `AVG`
* `GROUP BY`

---

## 問題3：サブクエリと条件指定

全社員の平均給与より高い給与を受け取っている社員を取得してください。

取得する項目は以下とします。

* 社員名
* 部署ID
* 給与

給与の高い順に並べてください。

### 使用する主な構文

* サブクエリ
* `AVG`
* `WHERE`
* `ORDER BY`

---

## 問題4：CASE式とJOIN

社員の情報を取得し、年齢に応じて以下のように分類してください。

| 年齢         | 区分   |
| ---------- | ---- |
| 30歳未満      | 若手   |
| 30歳以上40歳未満 | 中堅   |
| 40歳以上      | ベテラン |

取得する項目は以下とします。

* 社員名
* 部署名
* 年齢
* 年齢区分

### 使用する主な構文

* `INNER JOIN`
* `CASE`
* `WHEN`
* `ELSE`

---

## 問題5：総合問題

以下の条件をすべて満たすSQLを作成してください。

1. 社員名を取得する
2. 部署名を取得する
3. 給与を取得する
4. 賞与が `NULL` の場合は `0` として扱う
5. 給与と賞与を合計した「総支給額」を計算する
6. 部署ごとに総支給額の高い順で順位を付ける
7. 総支給額の高い順に結果を並べる

取得する項目は以下とします。

* 社員名
* 部署名
* 給与
* 賞与
* 総支給額
* 部署内順位

### 使用する主な構文

* `INNER JOIN`
* `COALESCE`
* `RANK()`
* `OVER`
* `PARTITION BY`
* `ORDER BY`

# 解答例

## 問題1

```sql
SELECT
    name,
    age,
    salary,
    COALESCE(bonus, 0) AS bonus
FROM employees
WHERE age >= 30;
```

---

## 問題2

```sql
SELECT
    d.department_name,
    COUNT(e.id) AS employee_count,
    AVG(e.salary) AS average_salary
FROM departments AS d
INNER JOIN employees AS e
    ON d.id = e.department_id
GROUP BY d.id, d.department_name;
```

---

## 問題3

```sql
SELECT
    name,
    department_id,
    salary
FROM employees
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
)
ORDER BY salary DESC;
```

---

## 問題4

```sql
SELECT
    e.name,
    d.department_name,
    e.age,
    CASE
        WHEN e.age < 30 THEN '若手'
        WHEN e.age < 40 THEN '中堅'
        ELSE 'ベテラン'
    END AS age_category
FROM employees AS e
INNER JOIN departments AS d
    ON e.department_id = d.id;
```

---

## 問題5

```sql
SELECT
    e.name,
    d.department_name,
    e.salary,
    COALESCE(e.bonus, 0) AS bonus,
    e.salary + COALESCE(e.bonus, 0) AS total_salary,
    RANK() OVER (
        PARTITION BY e.department_id
        ORDER BY e.salary + COALESCE(e.bonus, 0) DESC
    ) AS department_rank
FROM employees AS e
INNER JOIN departments AS d
    ON e.department_id = d.id
ORDER BY total_salary DESC;
```

## 10.2 演習を通して確認すること

今回の演習では、以下のようなSQLの組み合わせを扱いました。

| 演習  | 主な内容                      |
| --- | ------------------------- |
| 問題1 | `WHERE`、`COALESCE`        |
| 問題2 | `JOIN`、`GROUP BY`、集計関数    |
| 問題3 | サブクエリ、`ORDER BY`          |
| 問題4 | `JOIN`、`CASE`             |
| 問題5 | `JOIN`、`COALESCE`、ウィンドウ関数 |

SQLでは、1つの構文だけで処理を完結させるのではなく、複数の構文を組み合わせて使用することが多くあります。

演習問題を通して、各構文の使い方だけでなく、**「どのような処理を行いたいときに、どの構文を組み合わせればよいか」**を考えることが重要です。

問題を解く際は、最初から完成したSQLを書こうとせず、

1. 必要なテーブルを確認する
2. 必要なカラムを確認する
3. 条件を整理する
4. 必要に応じてテーブルをJOINする
5. 集計や計算を追加する
6. 最後に並び順を指定する

というように、処理を分けて考えるとSQLを組み立てやすくなります。
