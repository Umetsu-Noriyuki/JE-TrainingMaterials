# HTTP / REST API 基礎編

## 1. HTTPとは

### 1.1 HTTPとは

HTTP（Hypertext Transfer Protocol）は、**Web上でデータをやり取りするための通信ルール**です。

Webサイトを閲覧するときや、APIを利用するときなど、さまざまな場面でHTTPが使われています。

例えば、ブラウザでWebサイトにアクセスすると、裏側では次のようなやり取りが行われています。

```text
ブラウザ
   │
   │ HTTPリクエスト
   ↓
Webサーバー
   │
   │ HTTPレスポンス
   ↓
ブラウザ
```

簡単にいうと、

> 「このデータがほしい」とお願いする
> ↓
> 「このデータを返します」と返事が返ってくる

という通信です。

---

### 1.2 HTTPの基本的な流れ

HTTP通信は、基本的に**リクエストとレスポンス**の組み合わせで行われます。

```text
クライアント                    サーバー
    │                              │
    │  HTTPリクエスト              │
    │ ─────────────────────────→  │
    │                              │
    │  HTTPレスポンス              │
    │ ←─────────────────────────  │
    │                              │
```

#### HTTPリクエスト

クライアントからサーバーに対して、

> 「このデータをください」
> 「このデータを登録してください」

などの要求を送ります。

#### HTTPレスポンス

サーバーはリクエストを処理した結果を、

> 「取得できました」
> 「登録しました」
> 「そのデータは存在しません」

などの情報と一緒に返します。

---

### 1.3 クライアントとサーバー

HTTP通信では、主に**クライアント**と**サーバー**という2つの役割が登場します。

#### クライアント

サーバーに対してリクエストを送る側です。

例えば、

* Webブラウザ
* スマートフォンアプリ
* 業務システム
* APIを呼び出すプログラム

などがあります。

#### サーバー

クライアントからリクエストを受け取り、処理を行ってレスポンスを返す側です。

例えば、

* Webサーバー
* APIサーバー
* アプリケーションサーバー

などがあります。

```text
クライアント                    サーバー
    │                              │
    │ 「ユーザー情報をください」   │
    │ ─────────────────────────→  │
    │                              │
    │      「こちらです」          │
    │ ←─────────────────────────  │
```

---

### 1.4 HTTPとWebサイト・APIの関係

HTTPは、Webサイトを見るときだけに使われるものではありません。

例えば、次のような用途でHTTPが使われます。

```text
HTTP
├── Webサイト
│    └── ブラウザでページを表示する
│
└── API
     └── システム同士でデータをやり取りする
```

Webサイトでは、HTMLや画像などを取得するためにHTTPを利用します。

一方、APIでは、ユーザー情報や商品情報などの**データをシステム間でやり取りするためにHTTPを利用する**ことがあります。

例えば、

```text
業務システム
    │
    │ HTTP
    ↓
ユーザー情報API
    │
    │ ユーザー情報
    ↓
業務システム
```

このように、HTTPはAPIにおける通信手段としても利用されています。

---

### 1.5 HTTP APIとは

ここで「HTTP API」という言葉が出てきます。

HTTP APIとは、簡単にいうと、

> **HTTPを使って、システムから別のシステムの機能やデータを利用できるようにしたAPI**

のことです。

例えば、ユーザー情報を取得するAPIがあるとします。

```text
クライアント
    │
    │ HTTPリクエスト
    │ 「ユーザー123の情報をください」
    ↓
APIサーバー
    │
    │ HTTPレスポンス
    │ 「ユーザー123の情報です」
    ↓
クライアント
```

このように、HTTPを使ってAPIを利用するものを**HTTP API**と呼びます。

---

### 1.6 HTTP APIとREST API

ここは、この教材で特に覚えておきたいポイントです。

**HTTP APIとREST APIは完全に同じ意味ではありません。**

HTTP APIは、

> 「HTTPを使ってAPIを提供している」

という広い意味で使われます。

一方、REST APIは、

> 「RESTという設計思想・原則に沿って作られたAPI」

を指します。

そのため、イメージとしては次のようになります。

```text
API
└── HTTP API
     ├── REST API
     └── その他のHTTP API
```

つまり、

```text
HTTP API
  ↓
HTTPを使ってAPIを提供する

REST API
  ↓
HTTPを使い、RESTの考え方に沿ってAPIを設計する
```

という違いがあります。

この後の章では、まずHTTPのリクエスト・レスポンスについて詳しく学び、その後にAPI、REST APIへと話を進めていきます。

---

### 1.7 1章のまとめ

この章では、HTTPの基本的な考え方について学びました。

覚えておきたいポイントは以下です。

* **HTTP**は、Web上でデータをやり取りするための通信ルール
* HTTP通信は基本的に**リクエスト → レスポンス**で行われる
* リクエストを送る側を**クライアント**、受け取って処理する側を**サーバー**という
* HTTPはWebサイトだけでなく、**APIの通信にも利用される**
* **HTTP API**は、HTTPを使って機能やデータを提供するAPI
* **REST API**は、HTTP APIの中でもRESTの考え方に沿って設計されたAPI

まずは、

> **HTTP = 通信のルール**
> **HTTP API = HTTPを使ったAPI**
> **REST API = RESTの考え方に沿ったHTTP API**

という関係を押さえておきましょう。
