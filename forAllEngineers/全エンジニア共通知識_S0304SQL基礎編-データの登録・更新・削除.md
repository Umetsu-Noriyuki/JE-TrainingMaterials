## 4. データの登録・更新・削除

SQLでは、データを取得するだけではなく、データの登録・更新・削除も行うことができます。

---

### 4.1 INSERT文

**`INSERT`** は、テーブルに新しいデータを登録するときに使用します。

基本構文は以下のとおりです。

```sql
INSERT INTO テーブル名 (カラム1, カラム2, ...)
VALUES (値1, 値2, ...);
```

例えば、`users` テーブルに新しいユーザーを登録する場合は以下のように記述します。

```sql
INSERT INTO users (name, age, email)
VALUES ('山田太郎', 25, 'taro@example.com');
```

---

### 4.2 UPDATE文

**`UPDATE`** は、テーブルに登録されているデータを更新するときに使用します。

基本構文は以下のとおりです。

```sql
UPDATE テーブル名
SET カラム名 = 更新する値
WHERE 条件;
```

例えば、`id` が1のユーザーの年齢を26歳に変更する場合は以下のように記述します。

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

複数のカラムを更新することもできます。

```sql
UPDATE users
SET
    name = '田中太郎',
    age = 30
WHERE id = 1;
```

---

### 4.3 DELETE文

**`DELETE`** は、テーブルに登録されているデータを削除するときに使用します。

基本構文は以下のとおりです。

```sql
DELETE FROM テーブル名
WHERE 条件;
```

例えば、`id` が1のユーザーを削除する場合は以下のように記述します。

```sql
DELETE FROM users
WHERE id = 1;
```

---

### 4.4 UPDATE・DELETEの注意点

`UPDATE` や `DELETE` を使用するときは、`WHERE` の指定に注意してください。

```sql
UPDATE users
SET age = 30;
```

このSQLでは `WHERE` を指定していないため、`users` テーブルのすべてのレコードが更新されます。

`DELETE` も同様です。

```sql
DELETE FROM users;
```

この場合、`users` テーブルのすべてのレコードが削除されます。

そのため、特定のデータだけを更新・削除したい場合は、対象を指定する `WHERE` を付ける必要があります。

---

### 4.5 まとめ

| SQL      | 用途       |
| -------- | -------- |
| `INSERT` | データを登録する |
| `UPDATE` | データを更新する |
| `DELETE` | データを削除する |

特に `UPDATE` と `DELETE` はデータを変更・削除するため、実行前に `WHERE` の条件を確認することが重要です。
