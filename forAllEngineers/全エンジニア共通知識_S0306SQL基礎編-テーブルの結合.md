## 6. テーブルの結合

### 6.1 JOINとは

**`JOIN`** は、複数のテーブルを結合してデータを取得するときに使用します。

データベースでは、情報を用途ごとに複数のテーブルへ分けて管理することがあります。

例えば、以下のテーブルがあるとします。

### usersテーブル

| id | name |
| -- | ---- |
| 1  | 山田太郎 |
| 2  | 佐藤花子 |

### ordersテーブル

| id | user_id | product_name |
| -- | ------- | ------------ |
| 1  | 1       | ノートPC        |
| 2  | 2       | マウス          |

`orders.user_id` と `users.id` を利用すると、注文情報とユーザー情報を組み合わせることができます。

---

### 6.2 INNER JOIN

`INNER JOIN` は、結合条件に一致するデータだけを取得します。

```sql
SELECT
    users.name,
    orders.product_name
FROM users
INNER JOIN orders
    ON users.id = orders.user_id;
```

結果は以下のようになります。

| name | product_name |
| ---- | ------------ |
| 山田太郎 | ノートPC        |
| 佐藤花子 | マウス          |

---

### 6.3 LEFT JOIN

`LEFT JOIN` は、左側のテーブルのデータをすべて取得し、結合できるデータがある場合に右側のテーブルのデータを取得します。

```sql
SELECT
    users.name,
    orders.product_name
FROM users
LEFT JOIN orders
    ON users.id = orders.user_id;
```

注文履歴がないユーザーも結果に含めたい場合などに使用します。

---

### 6.4 JOINの基本構文

```sql
SELECT カラム
FROM テーブルA
JOIN テーブルB
    ON テーブルA.カラム = テーブルB.カラム;
```

`ON` の後に、テーブルを結合する条件を指定します。

---

### 6.5 まとめ

* `JOIN` は複数のテーブルを結合するときに使用する
* `ON` で結合条件を指定する
* `INNER JOIN` は条件に一致するデータを取得する
* `LEFT JOIN` は左側のテーブルのデータをすべて取得する
