## 2. SELECT文

### 2.1 SELECT文とは

**`SELECT`** は、データベースに保存されているデータを取得するときに使用するSQL文です。

基本的な構文は以下のとおりです。

```sql
SELECT 取得するカラム
FROM テーブル名;
```

`SELECT` で取得するカラムを指定し、`FROM` でデータを取得するテーブルを指定します。

---

### 2.2 すべてのカラムを取得する

テーブルにあるすべてのカラムを取得する場合は、`*` を使用します。

```sql
SELECT *
FROM users;
```

`*` は「すべて」を意味します。

---

### 2.3 特定のカラムを取得する

必要なカラムだけを取得する場合は、カラム名を指定します。

```sql
SELECT name
FROM users;
```

複数のカラムを取得する場合は、カンマ（`,`）で区切ります。

```sql
SELECT id, name, age
FROM users;
```

---
### 2.4 カラムに別名を付ける

取得したカラムに別名を付ける場合は、`AS` を使用します。

```sql
SELECT
    name AS user_name,
    age AS user_age
FROM users;
```

実行結果のカラム名が、それぞれ `user_name`、`user_age` になります。

---

### 2.5 SELECT文のまとめ

* `SELECT` で取得するカラムを指定する
* `FROM` で取得元のテーブルを指定する
* `*` を指定するとすべてのカラムを取得できる
* 複数のカラムはカンマで区切る
* `AS` を使用するとカラムに別名を付けられる
