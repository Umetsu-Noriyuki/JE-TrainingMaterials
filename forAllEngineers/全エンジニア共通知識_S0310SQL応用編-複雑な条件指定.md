# 1. 複雑な条件指定

基礎編では、`WHERE` 句と比較演算子を使用して条件を指定する方法を学習しました。

応用編では、より複雑な条件を指定するための演算子について説明します。

---

## 1.1 IN演算子

**`IN`** は、指定した複数の値の中に一致するデータを検索するときに使用します。

例えば、`department` が「営業部」「開発部」のいずれかであるユーザーを取得する場合、以下のように記述できます。

```sql
SELECT *
FROM employees
WHERE department IN ('営業部', '開発部');
```

`OR` を使用すると、以下のようにも記述できます。

```sql
SELECT *
FROM employees
WHERE department = '営業部'
   OR department = '開発部';
```

`IN` を使用することで、複数の値を指定する条件を簡潔に記述できます。

---

## 1.2 NOT IN

`IN` と反対に、指定した値に一致しないデータを取得する場合は **`NOT IN`** を使用します。

```sql
SELECT *
FROM employees
WHERE department NOT IN ('営業部', '開発部');
```

このSQLでは、「営業部」「開発部」以外の社員を取得します。

---

## 1.3 BETWEEN演算子

**`BETWEEN`** は、指定した範囲内にあるデータを検索するときに使用します。

例えば、20歳以上30歳以下のユーザーを取得する場合は以下のように記述できます。

```sql
SELECT *
FROM users
WHERE age BETWEEN 20 AND 30;
```

`BETWEEN` では、指定した最小値と最大値を含みます。

上記の例では、20歳と30歳のデータも対象になります。

---

## 1.4 LIKE演算子

**`LIKE`** は、文字列の一部が一致するデータを検索するときに使用します。

例えば、名前に「山田」が含まれるユーザーを取得する場合は以下のように記述します。

```sql
SELECT *
FROM users
WHERE name LIKE '%山田%';
```

`LIKE` では、`%` や `_` などのワイルドカードを使用できます。

| ワイルドカード | 意味           |
| ------- | ------------ |
| `%`     | 0文字以上の任意の文字列 |
| `_`     | 任意の1文字       |

例えば、以下のような検索ができます。

```sql
-- 「山田」で始まる名前
SELECT *
FROM users
WHERE name LIKE '山田%';
```

```sql
-- 「太郎」で終わる名前
SELECT *
FROM users
WHERE name LIKE '%太郎';
```

```sql
-- 「田」が含まれる名前
SELECT *
FROM users
WHERE name LIKE '%田%';
```

---

## 1.5 NOTと組み合わせる

条件を否定する場合は、`NOT` を使用できます。

例えば、名前に「山田」が含まれないユーザーを取得する場合は以下のように記述します。

```sql
SELECT *
FROM users
WHERE name NOT LIKE '%山田%';
```

---

## 1.6 条件を組み合わせる

複数の演算子を組み合わせることで、より複雑な条件を指定できます。

例えば、「20歳以上で、営業部または開発部に所属しているユーザー」を取得する場合は以下のように記述します。

```sql
SELECT *
FROM employees
WHERE age >= 20
  AND department IN ('営業部', '開発部');
```

---

## 1.7 条件指定のまとめ

* `IN`：指定した複数の値のいずれかに一致するデータを取得する
* `NOT IN`：指定した複数の値に一致しないデータを取得する
* `BETWEEN`：指定した範囲内のデータを取得する
* `LIKE`：文字列のパターンを指定して検索する
* `NOT`：条件を否定する
* `AND` や `OR` と組み合わせて複数の条件を指定できる

これらの演算子を使用することで、`WHERE` 句でより柔軟な条件を指定できるようになります。
