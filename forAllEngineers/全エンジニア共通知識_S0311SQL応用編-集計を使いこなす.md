# 2. 集計を使いこなす

基礎編では、`COUNT` や `SUM` などの集計関数と、`GROUP BY` を使用したデータの集計について学習しました。

ここでは、集計結果に対して条件を指定する方法や、複数の集計処理を組み合わせる方法について説明します。

---

## 2.1 HAVING句

**`HAVING`** は、`GROUP BY` によってグループ化した後のデータに対して条件を指定するときに使用します。

例えば、部署ごとの社員数を集計し、社員数が5人以上の部署だけを取得する場合は以下のように記述します。

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department
HAVING COUNT(*) >= 5;
```

---

## 2.2 WHEREとHAVINGの違い

`WHERE` と `HAVING` はどちらも条件を指定するために使用しますが、条件を適用する対象が異なります。

| 句        | 条件を適用する対象    |
| -------- | ------------ |
| `WHERE`  | グループ化する前のデータ |
| `HAVING` | グループ化した後のデータ |

例えば、20歳以上の社員だけを対象として、部署ごとの社員数が5人以上の部署を取得する場合は以下のようになります。

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
WHERE age >= 20
GROUP BY department
HAVING COUNT(*) >= 5;
```

このSQLでは、

1. `WHERE` で20歳以上の社員に絞り込む
2. `GROUP BY` で部署ごとにグループ化する
3. `COUNT` で部署ごとの社員数を数える
4. `HAVING` で社員数が5人以上の部署に絞り込む

という順番で処理されます。

---

## 2.3 複数の集計関数を使用する

1つのSQLで複数の集計関数を使用することもできます。

例えば、商品カテゴリごとの商品数、価格の合計、平均価格を取得する場合は以下のように記述します。

```sql
SELECT
    category,
    COUNT(*) AS product_count,
    SUM(price) AS total_price,
    AVG(price) AS average_price
FROM products
GROUP BY category;
```

結果は以下のようになります。

| category | product_count | total_price | average_price |
| -------- | ------------: | ----------: | ------------: |
| PC       |             5 |      500000 |        100000 |
| マウス      |            10 |       50000 |          5000 |
| キーボード    |             8 |       80000 |         10000 |

このように、1回のSQLで複数の集計結果を取得できます。

---

## 2.4 集計結果を並べ替える

集計結果に対して `ORDER BY` を使用することもできます。

```sql
SELECT
    department,
    COUNT(*) AS employee_count
FROM employees
GROUP BY department
ORDER BY employee_count DESC;
```

このSQLでは、社員数の多い部署から順番に表示します。

---

## 2.5 WHERE・GROUP BY・HAVING・ORDER BYの組み合わせ

これまで学習した構文を組み合わせることで、より実用的なSQLを記述できます。

```sql
SELECT
    department,
    COUNT(*) AS employee_count,
    AVG(age) AS average_age
FROM employees
WHERE age >= 20
GROUP BY department
HAVING COUNT(*) >= 5
ORDER BY employee_count DESC;
```

このSQLでは、

* 20歳以上の社員を対象にする
* 部署ごとにグループ化する
* 部署ごとの社員数と平均年齢を取得する
* 社員数が5人以上の部署に絞る
* 社員数の多い順に並べる

という処理を行っています。

---

## 2.6 集計を使いこなすためのポイント

集計処理では、**「どの段階で条件を指定するか」**を意識することが重要です。

基本的には、

```text
WHERE
  ↓
GROUP BY
  ↓
HAVING
  ↓
ORDER BY
```

という流れで考えると、SQLの構造を理解しやすくなります。

---

## 2.7 まとめ

* `HAVING` はグループ化した後のデータに条件を指定する
* `WHERE` はグループ化する前のデータに条件を指定する
* 複数の集計関数を1つのSQLで使用できる
* 集計結果に対して `ORDER BY` を使用できる
* `WHERE`、`GROUP BY`、`HAVING`、`ORDER BY` を組み合わせることで複雑な集計ができる
