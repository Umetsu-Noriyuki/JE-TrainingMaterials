## 5. データの集計

### 5.1 集計関数とは

**集計関数**とは、複数のレコードをまとめて計算するための関数です。

代表的な集計関数には以下があります。

| 関数      | 説明         |
| ------- | ---------- |
| `COUNT` | データの件数を数える |
| `SUM`   | 合計値を求める    |
| `AVG`   | 平均値を求める    |
| `MAX`   | 最大値を求める    |
| `MIN`   | 最小値を求める    |

---

### 5.2 COUNT

`COUNT` は、データの件数を数えるために使用します。

```sql
SELECT COUNT(*)
FROM users;
```

`users` テーブルに登録されているレコード数を取得します。

---

### 5.3 SUM

`SUM` は、指定したカラムの合計値を求めます。

```sql
SELECT SUM(price)
FROM products;
```

---

### 5.4 AVG

`AVG` は、指定したカラムの平均値を求めます。

```sql
SELECT AVG(price)
FROM products;
```

---

### 5.5 MAX・MIN

`MAX` は最大値、`MIN` は最小値を取得します。

```sql
SELECT MAX(price)
FROM products;
```

```sql
SELECT MIN(price)
FROM products;
```

---

### 5.6 GROUP BY句

**`GROUP BY`** は、指定したカラムの値ごとにデータをグループ化するときに使用します。

集計関数と組み合わせて使用することが多く、グループごとの件数や合計などを取得できます。

例えば、部署ごとの社員数を取得する場合は以下のように記述します。

```sql
SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```

実行結果は以下のようになります。

| department | COUNT(*) |
| ---------- | -------: |
| 営業部        |        5 |
| 開発部        |        8 |
| 総務部        |        3 |

このように、`GROUP BY` を使用すると、同じ値を持つレコードをグループ化して集計できます。

---

### 5.7 まとめ

* `COUNT`：件数
* `SUM`：合計
* `AVG`：平均
* `MAX`：最大値
* `MIN`：最小値
* `GROUP BY`：データをグループ化する
