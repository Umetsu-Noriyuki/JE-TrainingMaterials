# 3大RDBMS徹底比較研修（Oracle / PostgreSQL / MySQL）

システム開発やインフラ設計、マイグレーション（DB移行）において、**Oracle Database・PostgreSQL・MySQL** の3大RDBMSは避けて通れない存在です。しかし、「どれも同じSQLが動くデータベースだろう」と表面的な知識だけで扱うと、ロック競合による性能劣化や、SQL方言・NULLの扱いの違いによるバグ、ライセンスコストの想定外の高騰といった重大なトラブルを招きます。

本リポジトリは、単なる「構文の違いの暗記」にとどまらず、**「プロセス・メモリ構造や物理データ配置、MVCC（同時実行制御）の内部アーキテクチャの違いから、実務でハマりやすいSQLの落とし穴、DBA視点での監視・チューニングの勘所までを体系的に比較・理解すること」** を目的とした実践的な研修資料です。

新規システムの技術選定、異種DB間のマイグレーション設計、複数RDBMSを扱う現場でのパフォーマンス改善に直結する知識を身につけることができます。

## 🎯 研修のゴール
- ビジネス要件やシステム規模に基づき、**Oracle / PostgreSQL / MySQL の適切な選定基準とライセンス体系**を説明できる。
- **プロセスモデル（マルチプロセス vs マルチスレッド）** や **物理データ構造（ヒープ表 vs クラスタインデックス）** の違いが性能・運用に与える影響を理解できる。
- 各RDBMSにおける **MVCC（UNDO方式 vs 追記型/VACUUM方式）** の内部動作を把握し、ロック競合やテーブル肥大化の原因を特定できる。
- 移行や開発で事故になりやすい **SQL方言・データ型・NULL判定の違い** を事前に回避できる。

## 👥 対象者
- 新規システム開発やDB移行プロジェクトに携わるアプリケーションエンジニア・アーキテクト
- 複数のRDBMS環境の保守・運用・パフォーマンスチューニングを担当するエンジニア
- RDBMSの内部構造（メモリ・ストレージ・トランザクション制御）を横断的に比較して深く理解したい方

## 📚 前提知識
- 基本的なSQL（`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `JOIN`, `CREATE TABLE` など）の構文理解
- RDBMSの基本的な用語（テーブル、インデックス、トランザクション、ロック、コミット/ロールバック）の知識
