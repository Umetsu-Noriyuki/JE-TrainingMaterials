# データベース実行計画 入門ガイド 〜脱・初学者からDBAへ〜

システムの性能問題の多くはデータベースアクセス（SQL）に起因します。
本書は、「SQLの構文は書けるが、遅いクエリの調査方法がわからない方」や「今後データベース管理者（DBA）を目指すエンジニア」を対象に、データベース内部の挙動を可視化する最重要ツール **「実行計画（Execution Plan）」**の読み解き方を解説する技術ドキュメントです。

---

## 🎯 本書の到達目標

1. **可視化**：任意のSQLに対して自力で実行計画を出力し、ツリー構造（木構造）の処理順序を正しくトレースできる。
2. **構造理解**：代表的なアクセスパス（Full Scan / Index Scan）や結合方式（Nested Loops / Hash Join）の物理動作・長所短所を説明できる。
3. **ボトルネック特定**：スロークエリの実行計画を見て、インデックス無効化や統計情報の陳腐化による見積もり乖離を論理的に指摘できる。

## 🛠 検証環境・前提仕様

本書で掲載しているサンプルSQLおよび実行計画のテキストは、以下の標準的な構成をベースに検証・作成しています。

* **データベース製品**：Oracle Database（※基本概念・アルゴリズムはPostgreSQL / MySQL等でも共通です）
* **検証スキーマ構成**：
  * `customers`（顧客テーブル：約1,000件）
  * `orders`（注文テーブル：約100,000件）
* **検証用スクリプト**：テーブルDDLおよびダミーデータ生成スクリプトは [こちら](./SQL/setup_sample_data.sql) を参照してください。
