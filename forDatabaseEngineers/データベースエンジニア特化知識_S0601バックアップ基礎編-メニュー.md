# バックアップ / リストア基礎研修

システム開発や保守・運用において、ハードウェア故障や人的ミス（誤操作）といった不測の事態からデータを守り抜く **バックアップとリストア（リカバリ）** の設計・運用は、データベースエンジニアにとって最も重要な責務の一つです。

本リポジトリは、単なる「ダンプコマンドの実行方法」の学習にとどまらず、**「RPO/RTOの要件定義から、物理・論理バックアップの使い分け、トランザクションログを用いたポイントインタイムリカバリ（PITR）の内部動作、そして本番障害時に二次災害を防ぐ復旧手順までを体系的に理解し、実践できるようになること」** を目的とした実践的な研修資料です。

各テーマ（インデックス、SQLチューニングなど）から独立して学習可能であり、新規システムのバックアップ設計、本番メンテナンス時のデータ退避、緊急時の障害復旧対応に直結する知識を身につけることができます。

## 🎯 研修のゴール
- ビジネス要件から **RPO（目標復旧時点）** と **RTO（目標復旧時間）** を定義し、適切なバックアップ方式を選択できる。
- **物理バックアップ** と **論理バックアップ**、および **フル・差分・増分バックアップ** の仕組みとトレードオフを説明できる。
- トランザクションログ（アーカイブREDOログ / WAL / バイナリログ）を用いた **PITR（ポイントインタイムリカバリ）** の原理を理解し、誤操作の直前までデータを復元する手順を組み立てられる。

## 👥 対象者
- 新規機能開発や本番メンテナンスでデータの退避・復元を行うアプリケーションエンジニア
- バックアップ設計、定期リストア訓練、障害復旧対応を行う保守・運用担当者
- RDBMSのデータ保護の仕組み（トランザクションログとリストアの内部動作）を体系的に学びたい方

## 📚 前提知識
- 基本的なSQL（`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE TABLE` など）の構文理解
- RDBMSの基本的な用語（テーブル、トランザクション、コミット、ロールバック）の知識
